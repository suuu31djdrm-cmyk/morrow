# Morrow — Next.js

今週のテーマから、時間とエナジーに合う1週間をつくる、小さなプランナー。

## Windowsで起動

Node.js 22以降のLTS版をインストールしてから、ZIPを展開し、`package.json`があるフォルダーでPowerShellを開きます。

```powershell
npm ci
npm run dev
```

ブラウザで http://localhost:3000 を開きます。停止は Ctrl+C。

## Vercelへ配置

1. このフォルダーのファイルをGitHubの新しいリポジトリへアップロードします（`node_modules`、`.next`、秘密情報は含めない）。
2. Vercelで Add New → Project から、そのリポジトリを選択します。
3. Framework Preset が Next.js であることを確認し、Deploy。
4. 発行されたURLをiPhoneのSafariで開きます。

ビルドコマンドは `npm run build`。認証を使うにはAUTH_SETUP.mdに従って環境変数とSupabaseを設定します。未設定の場合はログイン機能が無効であることを表示します。端末内デモだけ試す場合は、明示的にALLOW_LOCAL_DEMO=trueを設定します。

## 実装済み

- テーマ作成・編集・削除、週ごとの管理
- 優先度・使える時間帯・集中しやすい時間帯からルールベースで予定を配分
- 集中する活動は設定した集中時間帯に配置。空き時間に少なくとも30%の余白を確保
- 週間カレンダー、スマホの日／週切り替え
- 予定の手動追加・編集・削除、重複チェック
- 手動編集した予定は再配分時も保持し、対応テーマの時間から差し引く
- ブラウザ内の自動保存、読み込み／保存エラーの表示

## この版の範囲

AIへの接続、通知、外部カレンダー連携、オフライン対応は未実装です。認証とユーザー別クラウド保存の接続コードを実装していますが、Supabase・プロバイダー・配信の本番設定が必要です。AUTH_SETUP.mdを参照してください。自動配分はAIではありません。活動の内容はユーザーが入力します。

既存HTMLを開いていたブラウザと、Vercel上のURLでは保存領域が異なります。旧データは自動転送されません。同一オリジンに旧形式の保存データがある場合は読み込めます。元の保存キーは削除しません。閲覧履歴／サイトデータを削除すると保存データも失われます。

今後AIを接続する場合は、サーバー側のRoute HandlerにAPI処理を追加し、Vercelの環境変数で秘密鍵を管理してください。公開APIには認証・利用上限も必要です。

## 検証

```powershell
npm run test
npm run typecheck
npm run build
```

ソースはReactコンポーネント、配分ロジック、保存処理を分離しています。HTMLをiframeで表示する構成ではありません。

## ブランド画像

提供された画像から切り出した背景透過PNGを `public/nature/` に15点同梱。ヘッダー・テーマカード・空状態・フッターにアクセントとして使用しています。元の線画を保持し、新しいモチーフは生成していません。画像は装飾として扱い、本文と重ねず、空のaltを設定しています。

## 表示言語

ブラウザの優先言語が日本語（ja / ja-JP）の場合は日本語、それ以外は英語を表示します。ブラウザの言語設定変更にも対応し、入力したテーマや予定は翻訳・変更しません。日本語／英語ともに週の開始は月曜、時刻は24時間表示です。

## 動きの演出

起動時に草木・鳥・うさぎがゆっくり現れ、自然のシーンが完全に消えてからmorrow. のロゴが現れます。起動演出に山は使いません。約4.8秒で終了し、セッション内で一度だけ表示。スキップボタン／Escapeでも終了します。OSやブラウザの「動きを減らす」設定では起動演出とマイクロアニメーションを無効にします。テーマ追加、予定追加、成功メッセージ、モーダル、ホバー時の線画にも短い補助アニメーションを設定しています。

## 目標の自動配分

テーマの保存時に、フォームで選んだ今週／来週へ自動配分します。手動予定と他テーマの既存予定は動かしません。同じテーマを編集した場合は、そのテーマの未編集の自動予定だけを作り直します。過去の時間帯へは配置しません。収まらない時間は明示し、無理に詰め込みません。「今週の配分を見直す」で週全体の再配分もできます。スマートフォンとタブレットでは日表示が初期状態です。週表示の横スクロールはカレンダー内部だけに収まります。

## 画面構成

ボトムメニューからホーム／カレンダー／目標作成／設定を切り替えます。ホームは常に今週のやることと目標達成度を表示。達成度は予定の完了チェックに基づき、予定を入れただけでは進みません。カレンダーの日表示は左右で前日／翌日（週をまたぐ移動にも対応）、週表示は前週／翌週へ切り替えます。週表示は表示幅を使い、480px未満ではカレンダー内だけ横スクロールできます。

## ログインと個人データ

Google／LINE／メールOTP／SMS OTPのサーバー側接続処理を実装。稼働には個人用Supabaseプロジェクト、各プロバイダー、SMTP・SMS・CAPTCHA、Vercel環境変数の設定が必要です。AUTH_SETUP.mdに手順と未検証事項があります。認証情報未設定の状態で実ログインが動くとは主張しません。
